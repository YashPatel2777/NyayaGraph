# API and integration contracts

> Part of the Legal GraphRAG Platform spec (v1.1). Section numbers (1.2, 3.2, R-09, E-05, P-06, G4...) are global across all files in `docs/`; see `docs/README.md` for the index. Do not renumber them: code comments and tests refer to them.

## 3. API and integration contracts

### 3.1 Conventions

- Base path /v1. JSON in UTF-8, except uploads (multipart/form-data). Timestamps are ISO 8601 UTC with a trailing Z.
- API-facing ids for cases, documents and jobs are bare UUID v4 strings; the node id adds the prefix from 2.1. Provision ids are used exactly as stored (for example sec:cpa-2019:38).
- Every request may carry X-Request-ID (1 to 64 characters). It is echoed on the response and generated by the server when absent.
- List endpoints take limit (1 to 100, default 25) and cursor, and return items and next\_cursor (null on the last page).

### 3.2 Identity and access (no authentication in v1)

- v1 has no authentication and no roles. Every request runs as one fixed local user whose id is DEFAULT\_USER\_ID (default local). No Authorization header is read.
- The user id is still stored on every case-scoped node and still passed through scope.py. Adding login later means changing one FastAPI dependency (get\_current\_user) from returning the constant to verifying a token; no schema, Cypher or endpoint change is needed.
- A user\_id in a request body or query string is ignored.
- Every endpoint, including /v1/admin/\*, is open to anyone who can reach the port. Uvicorn therefore binds to APP\_HOST (default 127.0.0.1); do not expose the service beyond the local machine until authentication is added.
- A case id that does not exist returns 404 CASE\_NOT\_FOUND.
- Rate limits (sliding window, in memory) are keyed by client IP address: POST /v1/query 30 per minute; document uploads 10 per minute; everything else 120 per minute. Exceeding a limit returns 429 RATE\_LIMITED with a Retry-After header.

### 3.3 Error envelope and codes

Every non-2xx response has this body:

```json
{
  "error": {
    "code": "CASE_NOT_FOUND",
    "message": "Case not found.",
    "details": {},
    "request_id": "7c1e0b9a-4d52-4a47-9a52-1f0f4c8e6a10"
  }
}
```

| HTTP | code | When | details |
| --- | --- | --- | --- |
| 404 | CASE\_NOT\_FOUND, DOCUMENT\_NOT\_FOUND, JOB\_NOT\_FOUND, PROVISION\_NOT\_FOUND | Id does not exist |  |
| 409 | CASE\_DELETING | Case is being deleted |  |
| 409 | NO\_READY\_DOCUMENTS | mode is case\_only and the case has no ready document |  |
| 413 | FILE\_TOO\_LARGE | Over the size limit in 3.4 | max\_bytes |
| 415 | UNSUPPORTED\_MEDIA\_TYPE | MIME type or file signature not allowed | allowed |
| 422 | VALIDATION\_ERROR | Body, query or form field invalid | fields: list of {loc, msg} |
| 429 | RATE\_LIMITED | Limit in 3.2 exceeded | retry\_after\_seconds |
| 500 | INTERNAL | Unhandled exception (message is generic; the stack goes to logs only) |  |
| 502 | LLM\_UPSTREAM\_ERROR | Groq failed after retries, or output stayed invalid | reason |
| 503 | DEPENDENCY\_UNAVAILABLE | Neo4j or Ollama unreachable after retries | dependency |
| 504 | QUERY\_TIMEOUT | Query exceeded 45 seconds |  |

### 3.4 Endpoints

| Method and path | Success |
| --- | --- |
| GET /health | 200 |
| POST /v1/cases | 201 |
| GET /v1/cases | 200 |
| GET /v1/cases/{case\_id} | 200 |
| DELETE /v1/cases/{case\_id} | 202 |
| POST /v1/cases/{case\_id}/documents | 202 (200 when duplicate) |
| GET /v1/cases/{case\_id}/documents | 200 |
| GET /v1/cases/{case\_id}/documents/{doc\_id} | 200 |
| GET /v1/jobs/{job\_id} | 200 |
| POST /v1/query | 200 |
| GET /v1/legal/provisions/{provision\_id} | 200 |
| POST /v1/admin/legal/ingest | 202 |
| GET /v1/admin/legal/acts | 200 |

**GET /health** returns 200 with status 'ok' when Neo4j answers, all four indexes are ONLINE, the Meta check passes and Ollama serves EMBED\_MODEL; otherwise 503 with the same body shape and a checks object (neo4j, indexes, embedding\_meta, ollama, each 'ok' or 'fail').

**POST /v1/cases** body: title (string, 1 to 200 characters). Returns 201 with case\_id, title, status ('active') and created\_at. **DELETE** sets status to 'deleting', cancels the case's jobs, and a background task removes every node with that case\_id plus the stored files; it returns 202.

**POST /v1/cases/{case\_id}/documents** is multipart with field file (required) and language (optional ISO 639-1 hint, used for audio). Allowed types and limits:

| Type | MIME | Limit |
| --- | --- | --- |
| PDF | application/pdf | 50 MB, 500 pages |
| Image | image/png, image/jpeg, image/tiff | 20 MB |
| Audio | audio/mpeg, audio/wav, audio/mp4, audio/x-m4a, audio/ogg | 200 MB, 120 minutes |
| Text | text/plain | 5 MB |

At most 200 documents per case. The file signature (first bytes) must agree with the declared MIME type. A new document returns 202 with doc\_id, job\_id, processing\_status ('queued') and duplicate (false). A repeated sha256 in the same case returns 200 with the existing doc\_id, job\_id null and duplicate true.

**GET /v1/jobs/{job\_id}** returns job\_id, type, status, stage, progress (0 to 100), warnings (list of string), error (null, or code and message), created\_at, started\_at and finished\_at. Stages for case\_document: stored, text\_extraction, chunking, embedding, entity\_extraction, entity\_resolution, legal\_linking, done. Stages for legal\_ingest: text\_extraction, parsing, embedding, writing, verification, done.

**POST /v1/query**

| Field | Type | Rules |
| --- | --- | --- |
| question | string | 3 to 2,000 characters, required |
| case\_id | UUID or null | Required unless mode is legal\_only; null with mode auto behaves as legal\_only |
| thread\_id | string or null | 1 to 64 characters; generated and returned when null. The LangGraph thread key is {user\_id}:{case\_id or none}:{thread\_id} |
| mode | string | auto (default), case\_and\_legal, legal\_only, case\_only |
| options.max\_case\_chunks | int | 1 to 10, default 5 |
| options.max\_provisions | int | 1 to 12, default 8 |
| options.include\_trace | bool | default false |

The 200 body is AnalysisResponse (3.5).

**GET /v1/legal/provisions/{provision\_id}** returns provision\_id, citation, text, status, in\_force\_from, amendment\_notes, parent (id and citation, or null), refers\_to and referenced\_by (lists of id and citation), and definitions (list of term and id for defined terms found in the text). Unknown id: 404 PROVISION\_NOT\_FOUND.

**POST /v1/admin/legal/ingest** is multipart with file and metadata (a JSON string with these keys):

| Key | Type | Notes |
| --- | --- | --- |
| act\_id | string | Slug, for example cpa-2019 |
| title, short\_title | string | As printed, and the short form used in citations |
| year | int |  |
| number | string | For example 35 of 2019 |
| jurisdiction | string | IN |
| as\_on\_date | date | The currency date printed on the source, for example 2026-09-01 |
| kind | string | act, rule or regulation |
| issued\_under | object or null | For rules: act\_id and sections (list of section numbers of the parent Act; SC-6) |
| amends | object or null | For an amendment notification (kind rule): act\_id of the principal rules and optional effective\_on (default as\_on\_date). The principal must already be ingested (SC-9, P-19 to P-21) |
| prescribes\_for | list or null | For rules: items {rule, section, note}. Creates PRESCRIBES\_FOR from the rule's Section to the parent Act's Section. An unknown rule or section fails the job with PARSE\_VALIDATION\_FAILED (SC-6) |
| expected\_sections | int or null | When set, a different parsed count fails the job (4.4, E-14) |
| replace | bool | true deletes the existing subtree for act\_id first |

Returns 202 with job\_id.

### 3.5 Response models (Python)

The LLM returns only ids, relevance text and relation. The verifier hydrates citation, status, act\_as\_on and excerpt from Neo4j, so these fields can never be invented by the model.

```python
from datetime import date
from typing import Literal, Optional
from pydantic import BaseModel, Field

class SourceRef(BaseModel):
    doc_id: str
    filename: str
    page: Optional[int] = None
    start_sec: Optional[float] = None
    end_sec: Optional[float] = None

class Fact(BaseModel):
    fact: str = Field(max_length=500)
    source_chunk_id: str
    source: SourceRef                     # hydrated by code

class Provision(BaseModel):
    provision_id: str                     # for example sec:cpa-2019:38 or cl:cpa-2019:2:7
    act: str                              # short title, hydrated
    act_as_on: date                       # hydrated from Act.as_on_date
    citation: str                         # for example 'Section 38(2), Consumer Protection Act, 2019'
    status: Literal['in_force', 'repealed', 'omitted']
    relation: Literal['direct', 'referenced', 'definition', 'interpretation']
    relevance: str = Field(max_length=500)   # the only LLM-written field
    excerpt: str = Field(max_length=600)     # copied from stored text by code

class Precedent(BaseModel):
    judgment_id: str
    citation: str
    relevance: str = Field(max_length=500)

class Confidence(BaseModel):
    level: Literal['low', 'medium', 'high']
    reasons: list[str]

class Trace(BaseModel):
    search_query: str
    issue_statement: str
    downgraded: bool = False
    counts: dict[str, int]       # case_candidates, case_final, legal_candidates, legal_final, expanded_nodes, dropped_citations
    timings_ms: dict[str, int]   # planner, case, issue, legal, expand, rerank, generate, verify, total
    llm: dict[str, int]          # prompt_tokens, completion_tokens

class AnalysisResponse(BaseModel):
    request_id: str
    case_id: Optional[str]
    thread_id: str
    intent: Literal['CONVERSATIONAL', 'CASE_ONLY', 'LEGAL_ONLY', 'CASE_AND_LEGAL']
    summary: str = Field(max_length=800)
    relevant_facts: list[Fact]
    applicable_provisions: list[Provision]
    precedents: list[Precedent]            # empty until judgments are ingested
    analysis: str = Field(max_length=4000)
    gaps_or_conflicts: list[str]
    confidence: Confidence
    disclaimer: str                         # constant, appended by code
    trace: Optional[Trace] = None           # present only when options.include_trace is true
```
